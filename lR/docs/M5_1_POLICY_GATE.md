# M5-1 — 렌탈 운영 정책 승인 게이트 (미승인 초안)

기준일: 2026-11-02 · 범위: 신규 `lR` 시연용 앱. 이 문서는 **영업 정책을 확정하지 않습니다.** 실제 금융 거래와 운영 MySQL 연결에 적용하지 않습니다.

## 포트폴리오 웹 전용 범위 변경 (2026-11-03)

- 본 프로젝트의 목표 결과물은 **웹 브라우저에서 직접 체험 가능한 고객/관리자 흐름**과 격리된 API·테스트 DB다. Android/iOS 실기기 QA는 사용자 결정으로 **SKIPPED (PASS 아님)**. [범위 문서](WEB_PORTFOLIO_QA_SCOPE.md) 참조.
- **데모 정책**과 **실운영 승인 정책**은 분리한다. 다음 패키지는 샘플 렌탈 기간·보증금·취소·환불을 `APP_MODE=demo` / `lr_test` 범위에서만 검증할 수 있다. 확정되지 않은 POL-01~05를 실제 영업 정책·법적 약관으로 표시하거나 운영 DB에 반영하면 안 된다.
- UI 전체를 반복적인 '시연용' 배지로 채울 필요는 없지만 **결제 실행 직전, 결제 결과, 계약/예약 확정으로 오인될 수 있는 지점에서는 '실제 결제 없음 / 주문·배송 확정 아님'을 명확하게 표시**한다.
- 상용 웹서비스 공개 배포를 결정한 경우에는 웹 브라우저 보안·접근성·개인정보 검증 및 운영 정책/PG 계약을 별도로 심사한다. 네이티브 기기 검증 제외를 상용 보안 완료로 해석하지 않는다.

## 승인 전 사용자에게 노출할 기준
- 거래 가능한 견적·계약·결제·배송 약속으로 표시하지 않습니다. 테스트 화면에는 `시연 전용`과 `실제 결제 없음`을 명확히 표기합니다.
- 제품은 제품 마스터(`Product`)와 개별 실물(`InventoryUnit`)을 구분합니다.
- 날짜는 `Asia/Seoul` `YYYY-MM-DD`, 반납일 제외 `[startDate,returnDate)`. 운영 정책 승인 시 최종 확인.
- 금액은 KRW 정수이며, 최종 렌탈 금액·보증금·배송비·할인·취소 수수료·환급액은 **서버 정책 버전**으로 계산합니다.
- 현재 시연은 견적·임시 홀드만 지원합니다. 실제 주문/PG 확정은 구현·승인 전까지 `501`로 차단합니다.

## 승인 가능한 릴리스 조건 (운영 준비)
1. 사업·법률 담당자가 각 정책 버전과 시행일, 소비자에게 노출할 문구, 수수료/예외 사례를 서면 승인.
2. 서버에 `PolicyVersion`과 변경 감사 로그 및 이전 버전 조회 기능 구현; 활성 승인 정책이 없으면 결제 확정 실패-차단.
3. 테스트 유형: 금액 위변조, 중복 웹훅, 만료된 홀드·견적, 손해배상/부분 환급, 취소 금액 재계산, 반납 지연, 주말·공휴일·타임존.
4. 개인정보 처리·PG 샌드박스 및 운영 백업/복구 검증 후 배포 게이트 별도 통과.

## M5-1 데모 로그인 범위
- 회원 생성·로그인·세션 회전·로그아웃을 **로컬 테스트 서버**에서만 시연합니다. 실제 이메일을 넣지 않으며, 검증되지 않은 계정을 영업 회원으로 취급하지 않습니다.
- iOS/Android 토큰은 `expo-secure-store` 사용, 브라우저는 메모리만 사용(새로고침 시 비로그인). 토큰과 테스트 비밀번호를 URL/analytics/log/Redux/AsyncStorage에 기록하지 않습니다.
- HTTPS 아닌 LAN 주소로는 **로그인·회원가입 비활성**. 네이티브 실기기에서 로그인 테스트하려면 HTTPS 테스트 터널 또는 유효한 개발용 TLS가 필요합니다.
- 서버 /me 성공 후에만 로그인 상태 표시; 만료/회수 토큰은 폐기하며 로그아웃 시 로컬 지움. 로그아웃 중 오프라인이면 서버 세션 해제를 확정할 수 없으므로 사용자에게 위험을 알립니다.
- 바이오메트릭 장치인증, 이메일 검증, 분산 로그인 제한, 비밀번호 재설정·MFA, 실기기·침투테스트는 **아직 미완료**. 네이티브 키체인 구현은 CI 타입/웹 빌드 통과만으로 실제 동작을 입증할 수 없습니다.

참고: [Expo SecureStore](https://docs.expo.dev/versions/latest/sdk/securestore/), [OWASP Authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html), [M1 ADR](DECISIONS_M1.md).
