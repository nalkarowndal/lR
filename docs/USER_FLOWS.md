# M1 — 핵심 사용자 여정 및 예외 시나리오

**상태:** 플로우 설계 기준선 v1.0 · **작성:** 2026-11-02
**전제:** API, 인증, PG, 배송 연동은 아직 미구현. 본 문서의 흐름은 미래 구현을 위한 상태 계약.

## F01 고객 렌탈
1. 홈/렌탈 → 브랜드/검색/필터 → 상품 상세.
2. 상품 조건과 상태·대여료 확인 → KST 시작일/반납일 선택.
3. 서버 `availability` 확인 → `quote`로 KRW 세부 견적/보증금 안내.
4. 로그인 또는 가입 (미로그인 시 복귀 URL 보존) → 주소/취소 규정 동의.
5. 서버가 `InventoryHold`를 원자적으로 생성하고 `expiresAt`을 반환; 결제창은 해당 `checkoutId`로만 연동.
6. 테스트 PG에서는 **모의 결제 표시**, 운영 PG에서는 서버 측 승인 확인 이후에만 `Rental=CONFIRMED`.
7. 완료 화면 → 내 대여 → 출고 → 배송/사용 → 반납요청 → 검사·청소 → 완료/재고 공개.

**예외:** 잘못된 날짜=422; 해당 실물 선점=409 `INVENTORY_CONFLICT` (달력 다시 열기); 홀드 만료=409 `HOLD_EXPIRED`; 결제 실패=체크아웃 복구/홀드 만료 정리; 네트워크 타임아웃=서버 요청 ID/멱등키 기반 재조회; 사용자 취소=내역 취소 후 원복.

## F02 명품 구매
1. 스토어/검색 → 상품 상세에서 **구매 가능** 확인.
2. 장바구니 또는 바로 구매 → 배송지/최종 KRW 금액/상품 상태·환불 조건 확인.
3. 상품 unit을 결제대기 `InventoryHold`로 확보하고 `Order` 생성.
4. PG 인증 → 서버의 주문 금액·고유 orderId·paymentKey 검증 → PG 승인.
5. 승인 성공 뒤 `Order=PAID`, `InventoryUnit=SOLD` 확정; 관리자 출고.
6. 취소/거절/만료 시 `Hold=RELEASED/EXPIRED`, 재고 상태 READY로 복귀.
**예외:** 동일 멱등키/같은 본문 재요청은 같은 결과; 카드 결제 타임아웃은 무조건 새 주문 생성 금지; 이미 판매된 item 구매 시 409.

## F03 수선/복원
1. 수선 탭 → 서비스 안내 → 신청서.
2. 로그인 → 대상 물품·문제점·사진·연락/수거 희망 입력.
3. 서버 검증 후 사진을 비공개 저장; `RepairRequest=SUBMITTED`.
4. 관리자 접수/검수 → 견적 제시 → 고객 수락 또는 거절 → (필요하면 결제) → 작업 진행 → 배송/완료.
**예외:** 잘못된 이미지 유형·크기=422/413, 권한 거부=설정 안내, 네트워크 끊김=재시도, 타인 파일 접근=403/404. 약관이 확정되기 전 견적 승인을 실제 구매/청구로 처리하지 않는다.

## F04 상품 위탁 판매 (P1)
브랜드 → 제품 종류/상태 등급/보증서·사진 → 예상/확정 감정 구분 → 연락처·동의 → 수거·검수 → 위탁계약 → 판매/정산 상태 확인. 기존 `ShopSell`의 단계식 UX 보존. **데모 견적을 계약/정산과 혼동하지 않는다.**

## F05 회원·찜·마이
비로그인도 상품 탐색 가능 → 찜/예약/구매/수선 신청 시 가입 안내 → 인증 → 원래 진입점으로 복귀. 로그인 후 찜은 DB 기준으로 복원되며 내 예약·결제·수선만 표시. 만료 세션은 안전하게 갱신 또는 재로그인; 로그인 이전 임시 찜은 사용자 동의 후 동기화.

## F06 관리자 상품/재고/예약
관리자 로그인 + 서버 RBAC → 상품 모델 생성/수정 → 실물 입고·등급/사진/증빙 등록 → 출고와 예약 상태 확인 → 반납 검수(오염/파손/보증금 처리 절차 분리) → 청소/수선 → READY → 감사 로그. `RecruitApp`은 인력 운영 관리자만 접근하는 독립 모듈.

## F07 에디토리얼
CONTENT_EDITOR 작성 → DRAFT 저장 → 관리자 검토/발행 → 고객 홈에 PUBLISHED만 공개 → 보관/비공개 전환 시 비노출. 이미지 출처·라이선스 검증 전 발행 차단.

## 오류 UX 계약
| 코드 | UI 동작 |
|---|---|
| UNAUTHENTICATED | 로그인 → 원래 화면 복귀 |
| FORBIDDEN | 접근 권한 안내 (민감 리소스는 존재 여부를 숨기는 404도 허용) |
| VALIDATION_ERROR | 항목별 오류·포커스·재수정 |
| INVENTORY_CONFLICT | 사용 가능 날짜 다시 조회, 바뀐 가격·기간 재확인 |
| HOLD_EXPIRED | 홀드 다시 생성, 중복결제 우려 시 상태 조회 우선 |
| QUOTE_EXPIRED | 이전 견적 폐기하고 재산정 |
| PAYMENT_PENDING | 결제 상태 재조회, 중복 요청 금지 |
| PAYMENT_FAILED | 안전 재시도/다른 결제수단 선택 |
| RATE_LIMITED | 잠시 후 재시도, 개인정보 유출 없는 메시지 |
| SERVER_UNAVAILABLE | 오프라인/네트워크 오류 분리, 읽기 페이지 캐시 및 재시도 |
