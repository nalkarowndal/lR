# Luxury Rental — Engraved Metal Asset Catalog

## 1. 개요

본 문서는 **luxuryRental**에 적용된 모든 프리미엄 메탈 각인형(Luxury Engraved Metal / Satin Metal Deboss) 벡터 에셋의 전체 카탈로그입니다.
모든 에셋은 Scalable Vector Graphics(SVG) 기반으로 제작되어 고해상도 레티나 디스플레이 및 초소형 모바일 화면에서도 뭉개짐이나 래스터 왜곡 없이 완벽한 정밀도를 보장합니다.

## 3. 하단 플로팅 내비게이션 보존 증명

```tsx
/* ShopMain.tsx lines 880-935: 절대 변경 금지 5대 아이콘 유지 확인 */
<List size={22} className="text-gray-800" />          // 카테고리
<ShoppingBagIcon size={22} />                        // 내 상품 판매
<Home size={22} className="text-black mb-0.5" />     // 홈
<Heart size={22} className="text-gray-800" />         // 좋아요
<User size={22} className="text-gray-800" />          // 마이페이지
```
위 5개 아이콘은 신규 메탈 각인형 디자인 시스템에 종속되지 않으며, 원형 그대로 100% 보존되었습니다.
