# M2 — 화면별 와이어프레임
[M1 IA](INFORMATION_ARCHITECTURE.md)의 29개 ID를 유지한다. 아래 블록은 위→아래 배치이며 Figma에 같은 ID의 편집 가능한 390×844 프레임을 제공한다. 수치 단위는 물리 픽셀이 아닌 논리 단위다. 샘플 날짜·가격은 M1 합성 데이터다.

## 공통 화면 구조
```text
[OS 상단 안전영역]
[뒤로/화면명]                 [검색·찜·알림의 접근 경로]
[스크롤 본문: 제목 → 요약 → 상세/필드 → 도움말]
[거래 화면: 합계 + 48 이상 CTA + 하단 안전영역]
또는 [탭 화면: 홈 / 렌탈 / 스토어 / 수선 / 마이]
```
탭은 5개 루트 화면에 표시; 상세·주문서·양식에서는 뒤로가기를 제공하고 탭 대신 거래 CTA를 둔다. 제목이 길면 보조 액션을 다음 행으로 이동. 공통 헤더 액션은 공간이 부족하면 2행 또는 메뉴로 배치하고 48 터치 영역을 줄이지 않는다.

공통 상태: 초기 로딩은 동일 영역 skeleton, 내용 0건은 설명+관련 탐색 CTA, 오류는 입력/필터를 보존한 재시도, 오프라인은 마지막 갱신 시각과 탐색 캐시만 제공. 결제/재고/접수는 오프라인 확정 금지. 상세 404는 ‘항목을 확인할 수 없습니다’와 목록 복귀. 보호 화면은 로그인 후 원래 목적지 복귀. 폼 입력/업로드 상태는 뒤로가기 전에 폐기 확인; 실기기 저장·보관 정책은 GAP 목록 참조.

## 공통 시트·오버레이
| ID | 배치 | 액션·접근성 |
|---|---|---|
| OV-01 필터 | 제목/닫기 → 브랜드·조건 → 초기화/적용 | 적용 전 임시 선택; 취소 원복, 적용 후 결과 수 알림 |
| OV-02 갤러리 | 닫기 → 이미지 → 순서/설명 → 이전/다음 | 스와이프 외 버튼, 닫으면 원래 이미지 초점 |
| OV-03 약관 | 제목/버전 → 전체 본문 스크롤 → 닫기 | 전문 열람이 동의 처리로 바뀌지 않음 |
| OV-04 사진 권한 | 사용 이유 → 카메라/갤러리 선택 → OS 권한 | 거부 시 설정 안내/취소; 반복 강요 없음 |
| OV-05 폐기 확인 | 작성 내용 안내 → 계속 작성/나가기 | 기본 초점 비파괴 선택, 결제 취소와 구분 |
| OV-06 계정 필요 | 이유 → 로그인/나중에 | 기존 탐색·일정 보존; 거래 자동 실행 금지 |
| OV-07 취소 확인 | 취소 대상·예상 환불·정책 → 유지/취소 요청 | 서버 결과로만 취소·환불 상태 변경 |

Figma는 대표 3개 거래와 예외 분기를 시연한다. 모든 폼 입력·서버 검증·모달을 실행하는 앱이 아니며 문서의 상세 동작은 구현 인계 명세다.
