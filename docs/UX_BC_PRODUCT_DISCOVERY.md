# UX-BC — 상품 미디어·상세·검색·태블릿 반응형

## 범위 (기존 브랜드·5탭 유지)
- 상품 미디어 계약 `Product.media?: {url,alt}[]` 지원. 외부 이미지 URI는 **HTTPS only**, 인증정보 포함 URI 차단, 최대 8장, 적합한 alt 텍스트 필수.
- 백엔드 API가 아직 제공하지 않는 미디어는 **시연용 일러스트**로 표시하며 실물 사진/공식 이미지인 것처럼 표현하지 않는다. 브랜드/상품별 이미지 URL을 승인·등록하는 관리 기능 및 이미지 사용권 검증은 별도 후속 작업이다. 이미지 로드 실패 시 데모 폴백.
- 상품 카드: 카테고리, 브랜드, 제품 등급과 채널별 가격 표시. 상세: 선택 가능한 다중 이미지 인덱스, 데모 정보/실물 검수 주의, 스토어 진입 시 구매 CTA 우선, 렌탈 진입 시 대여 우선.
- 검색: 카테고리, A/B/S 상태등급, 현재 목록 내 가격 정렬. `useProductList`가 먼저 조회한 **현재 불러온 페이지**에만 클라이언트 필터·정렬을 수행하므로 전체 DB 인기순/가격순이라고 주장하지 않는다. 검색어는 기존 API의 서버 측 검색/기존 debounce를 유지한다.
- 상품 그리드: 모바일 2열, 640~959px 태블릿 3열, 960px 이상 4열. 다른 화면의 5탭과 safe-area 동작은 그대로 둔다.
- 필터 입력은 저장·전송되지 않으며 인증/결제 API 변경 없음.

## 자동 검증
- DOM 이미지 소스 사용 시 HTTPS와 접근성 설명 검증을 단위 테스트에 추가.
- 상품 카테고리/등급/가격 정렬의 순수 함수 테스트.
- Playwright 모바일 검색·상세 및 768px 3열 → 1024px 4열을 검증하고 screenshot artifacts 보관.
- 타입체크/Node tests/Expo web export + 기존 API 장애 화면 회귀 CI PASS 전 병합 금지.
- 시각 QA PNG는 자동 수집되며 수동 콘텐츠 검토·실 Android/iOS 접근성/기기 QA는 별도 미완료.

## 운영 전 후속 작업
1. **실제 상품 사진**은 판매/위탁 당사자의 이용허락·저작권·검수·CDN 접근 통제 확인 후 `media` 필드에 공급해야 한다. 지금은 실제 사진을 추가하지 않았음.
2. API 페이지 전체 정렬·필터가 필요하면 SQL/쿼리 계약과 페이지네이션을 확장하고 UI 필터 범위를 업데이트.
3. 스크린리더·동적 폰트·상품 사진 상세 확대·태블릿 주요 내비게이션을 실기기에서 확인.
4. 결제/PG 정책 미승인 상태 유지. 운영 MySQL과 레거시 원본 웹 변경하지 않음.
