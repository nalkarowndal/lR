# LUXURY RENTAL — 전 페이지·상호작용 스크린샷 및 시각 검증 영상 총람

본 디렉토리(`docs/screen/`)는 LuxuryRental 플랫폼의 **모든 화면, 모든 버튼, 모달 팝업, 폼 입력, 탭 전환, 인증 가드 및 관리자 기능에 이르는 전수 스크린샷(130건)**과 **핵심 기능 8대 상호작용 녹화 영상(WebM 60fps & 고화질 애니메이션 GIF)**을 체계적으로 수록한 공식 검증 아카이브입니다.

1. **전 페이지 무결성 (Zero Broken Assets)**:
   - 모든 상품 카드, 브랜드 칩, 카테고리 LNB, 실시간 검색 결과의 룩북 이미지가 100% 정상 렌더링되며 이미지 깨짐(엑스박스) 0건을 유지합니다.
2. **소셜 인증 및 뒤로가기(bfcache) 완벽 방어**:
   - 카카오 및 Google OAuth 외부 페이지 진입 후 브라우저 뒤로가기 복귀 시 '연결 중' 잠금 현상 없이 0ms 즉시 클릭 가능 상태로 복구됩니다.
3. **완전한 시각 검증 패키지 제공**:
   - `docs/screen/` 디렉토리에 정적 스크린샷 130종과 동적 상호작용 영상 8종(WebM + GIF)이 모두 구비되어 있어, 언제든지 플랫폼의 모든 동작 흐름을 시각적으로 재생 및 확인할 수 있습니다.
