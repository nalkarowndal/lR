## 1. 개요

사용자 경험(UX)의 완성도를 높이기 위해 파일 업로드 처리, 즉각적인 로컬 미리보기, 인터랙션 피드백 및 모달 시스템을 상용 서비스 수준으로 전면 고도화하였습니다.

---

## 2. 마이페이지(ShopMyPage) 프로필 사진 업로드 UX

### 2.1 파일 선택 및 로컬 미리보기
- **파일 인풋**: 숨겨진 `<input type="file" accept="image/*">`와 스타일링된 "사진 업로드" 버튼 연결.
- **클라이언트 검증**:
  - MIME 타입 검사 (`image/png`, `image/jpeg`, `image/webp`).
  - 용량 제한 (최대 2MB): 초과 시 직관적인 에러 메시지 노출.
- **실시간 프리뷰**: `FileReader.readAsDataURL`을 활용하여 모달 내 원형 아바타에 즉시 반영.
- **기본값 복원**: 프로필 이미지가 등록된 경우 "기본값" 복원 버튼 노출.
- **대체 수단 제공**: 로컬 파일 업로드 외에 웹 이미지 URL 직접 입력 필드도 하단에 보존.

---

## 3. 관리자 대시보드(ShopAdmin) 룩북 갤러리 관리 UX

### 3.1 파일 직접 업로드 및 대표 이미지 지정
- 관리자가 상품 상세 갤러리 모달에서 컴퓨터 내 사진 파일을 직접 선택할 수 있는 `📁 파일에서 선택` 버튼 신설.
- 선택 시 파일의 썸네일 미리보기 및 파일명 요약 카드 표시.
- `대표 이미지로 설정` 체크박스를 통해 첫 번째 룩북 이미지 또는 대표 썸네일로 즉시 지정 가능.
- 기존 이미지 삭제 및 대표 이미지 변경 기능과의 유기적 연동.

---

## 4. 모달 및 팝업 일관성

- **모달 레이어**: `z-[200]` 레벨에서 배경 블러(`backdrop-blur-xs`)와 암전 오버레이 적용.
- **애니메이션**: `animate-scaleUp` 및 부드러운 페이드인 적용.
- **ESC 키 및 백드롭 클릭 핸들링**: 키보드 접근성(A11y) 완비.
