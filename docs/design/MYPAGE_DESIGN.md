# luxuryRental 마이페이지 디자인 명세서 (MYPAGE_DESIGN)

## 1. 개요 및 화면 목적

기존 빈 컴포넌트(`sub/MyPage.tsx`)를 대체하고 하단 바텀 네비게이션의 '마이페이지' 버튼과 유기적으로 연결되는 전용 사용자 중심 화면입니다. 사용자의 계정 프로필, 찜한 명품 위시리스트, 렌탈 이용 현황, 위탁 판매 신청 내역을 한눈에 관리할 수 있습니다.

## 3. 프로필 수정 기능 명세

- **트리거**: 프로필 카드 우측 상단의 `Edit3` 아이콘 클릭.
- **수정 항목**:
  - 이름 (`name`)
  - 연락처 (`phone`)
  - 프로필 이미지 URL (`avatar_url`)
- **보안 검증**:
  - `role` 필드는 프런트/백엔드 모두 수정 불가능하도록 완전히 격리되어 권한 상승 공격을 차단합니다.
