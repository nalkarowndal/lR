# luxuryRental 설정 페이지 디자인 명세서 (SETTINGS_PAGE_DESIGN)

## 1. 디자인 방향성 및 레이아웃

- **스타일**: Modern Luxury Minimal Mobile UI
- **컨테이너**: 모바일 중심 중앙 컨테이너 (`max-w-md`), 상단 고정 헤더, 하단 세이프 패딩 (`pb-28`)
- **색상 체계**:
  - 배경: `bg-gray-50`
  - 섹션 카드: `bg-white`, `border-gray-100`, `rounded-2xl`, `shadow-sm`
  - 텍스트: 제목 `text-gray-900 font-bold`, 부가설명 `text-gray-400 text-xs`
  - 관리자 전용 배너: `bg-gradient-to-r from-slate-900 via-indigo-950 to-slate-900`, `border-indigo-500/30`

## 3. 상호작용 및 모달 명세

1. **비밀번호 변경 모달**: 현재 비밀번호, 새 비밀번호(6자 이상), 확인 입력 및 `api.changeMyPassword` 연동.
2. **로그아웃 확인 다이얼로그**: `ConfirmDialog`를 통한 실수 방지 컨펌 후 `logoutUser()` 실행.
3. **고객센터 / FAQ / 약관 모달**: 전문 안내 내용을 모바일 뷰포트 내 아늑한 모달 팝업으로 제공.
4. **회원 탈퇴 안내 모달**: 렌탈 및 판매 잔여 건 안내 및 1:1 상담 접수 절차 안내.
