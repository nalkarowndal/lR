## 타이포그래피와 숫자
| 토큰 | 크기/행간 (논리 단위) | 무게 | 용도 |
|---|---|---|---|
| display | 28/38 | 700 | 홈의 주요 메시지 |
| title | 24/34 | 700 | 화면 제목 |
| heading | 20/30 | 700 | 섹션 |
| body | 16/24 | 400 | 설명·입력 |
| label | 14/22 | 500 | 버튼·보조 라벨 |
| caption | 12/18 | 400 | 부가 정보·탭; 중요 조건은 body 이상 |

한글은 단어 단위 줄바꿈을 우선하되 긴 식별자는 줄바꿈 가능. 가격은 숫자 정렬, 원 기호/‘원’ 표기를 일관되게 사용한다. 상품 카드 제목만 기본 2줄 후 상세에서 전체 제공. 거래 금액·오류·약관·CTA에는 말줄임 금지. 텍스트 배율을 강제로 1로 고정하지 않는다. Figma Noto Sans KR 대체를 앱 Pretendard 적용 완료로 간주하지 않는다.

## 간격·모양·그림자
4/8/12/16/20/24/32/40/48 단위 간격. 화면 좌우 20, 작은 화면 16. 카드 내부 16, 섹션 사이 24, 필드 사이 16. 반경 8/12/16/24/9999; 버튼 12, 카드 16, 탭 9999. 1단위 장식선. 떠 있는 탭의 그림자는 y=8, blur=30, black 8%를 출발값으로 플랫폼별 조정. 그림자가 조작 가능 여부의 유일한 단서가 되지 않는다.

## 이미지·아이콘·모션
상품은 4:3 또는 1:1, 내용 손실 없는 contain 기본; 에디토리얼만 crop 가능. 썸네일·상태 사진은 같은 실물과 연결해야 한다. 디자인의 ‘상품 이미지 영역’은 와이어프레임 표시이며 승인된 실물 사진이 아니다. 실제 사진·브랜드 로고는 권리 확인 후 교체.
아이콘은 원본 Lucide 계열 선형 스타일을 이어가되 의미 라벨과 48 단위 터치 영역을 둔다. 와이어프레임에서는 텍스트 액션을 사용한다.
화면 전환 제안 180~240ms, 시트 220ms, 눌림 80ms. 모션 감소에서는 즉시 전환/짧은 fade, 스케일·패럴랙스·자동 캐러셀 제거. 숫자 카운트다운은 매초 낭독하지 않는다.
