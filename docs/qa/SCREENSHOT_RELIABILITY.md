# luxuryRental — Phase 6 자동 스크린샷 무결성 및 해시 신뢰성 보고서

## 1. 개요 및 배경

Phase 5 자동 QA 스크린샷 캡처(102개)에서 발생했던 주요 결함은 **동일 화면이 불필요하게 중복 캡처되는 현상(14개 중복 그룹, 25개 중복 사본)**이었습니다.
이로 인해 시각적 검수 신뢰도가 저하되고, 실제 상호작용(버튼 클릭, 모달 오픈/클로즈, 탭 전환)이 정상 실행되었는지 검증하기 어려웠습니다.

Phase 6에서는 다음 5가지 핵심 기법을 도입하여 자동 스크린샷의 무결성과 신뢰성을 100% 회복했습니다.

---

## 2. Phase 6 스크린샷 무결성 개선 기법

### 2.1 SHA-256 실시간 해시 검증 및 중복 조기 경보
- `capture()` 함수 실행 시 매 캡처 직후 스크린샷 버퍼의 SHA-256 해시를 계산하여 `seenHashes` Set에 등록.
- 직전 스크린샷과 동일한 해시가 감지될 경우 콘솔에 즉시 `[DUPLICATE WARNING]` 경고를 출력하고 원인을 추적.

### 2.2 모달 라이프사이클 격리 및 잔류 방지
- **원인 분석**: Phase 5에서는 관리자 갤러리 모달의 닫기 버튼이 아이콘(`<i class="fa-solid fa-xmark"></i>`)으로만 구성되어 텍스트 검색 기반 클릭 함수가 작동하지 않았고, 이로 인해 모달이 닫히지 않고 이후의 모든 화면(88~102번)에 잔류했습니다.
- **해결 방안**:
  1. `ShopAdmin.tsx` 갤러리 모달에 명시적인 `'닫기'` 텍스트 버튼 및 `aria-label="갤러리 닫기"` 추가.
  2. 탭 전환(`mainTab`, `recruitTab`) 시 모든 하위 모달을 강제 초기화하는 `useEffect` 리셋 훅 구현.
  3. `window.__lrCloseAdminModals` 전역 헬퍼를 노출하여 테스트 스크립트에서 안전하게 모달을 일괄 정리할 수 있도록 보장.

### 2.3 8-Grid 메뉴 모달 전수 닫기 동기화
- 메인 화면 8-Grid 메뉴(07~14번) 클릭 시 팝업되는 `serviceInfoModal`의 하단 닫기 버튼 텍스트가 `'닫기'`임에도 기존 스크립트가 `'확인'`을 클릭하여 모달이 닫히지 않았던 결함을 전수 수정했습니다.

### 2.4 장바구니 및 모의 주문 결제 플로우 버튼 텍스트 일치
- `CART` -> `SHIPPING` 진입 버튼: `'주문서 작성으로 이동'`
- `SHIPPING` -> `ORDER_COMPLETE` 결제 승인 버튼: `'최종 결제 및 렌탈 예약 접수'`
- `ORDER_COMPLETE` 모달 닫기 버튼: `'쇼핑 계속하기'`
- 각 스텝별 정확한 버튼 텍스트와 500ms 이상의 애니메이션 렌더링 대기 시간을 보장하여 장바구니부터 주문 완료까지의 흐름이 단 1건의 해시 중복 없이 완벽히 기록되도록 개선했습니다.

### 2.5 뷰포트별 수평 밀림(Horizontal Drift) 0px 방지
- 데스크톱 1440px 해상도에서 회원가입 및 비밀번호 재설정 모달 오픈 시 브라우저 인풋 포커스 스크롤로 인해 발생하던 130px 수평 밀림 현상을 `html, body { overflow-x: hidden; max-width: 100vw; }` 및 `window.scrollTo({ left: 0, top: 0 })`를 통해 100% 제거했습니다.
