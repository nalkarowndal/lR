# luxuryRental — Phase 6 관리자 센터 및 권한 보안 워크플로우 QA 보고서

## 1. 개요 및 설계 원칙

럭셔리렌탈의 관리자 시스템은 쇼핑몰 상품 운영과 오프라인 35개 매장 구인/채용 관리를 통합 지원하는 하이브리드 대시보드입니다.
Phase 5에서 발생했던 가장 심각한 시스템적 결함은 **관리자 갤러리 모달이 닫히지 않고 이후의 탭 및 반응형 테스트 전반에 잔류했던 문제**와, **일반 회원이 관리자 대시보드 URL에 무단 접근할 수 있는 보안 취약점**이었습니다.

Phase 6에서는 다음 3가지 핵심 아키텍처 개선을 적용했습니다.

## 2. 관리자 모달 라이프사이클 격리 메커니즘

### 2.1 탭 전환 시 강제 리셋 (`ShopAdmin.tsx`)
```tsx
useEffect(() => {
  setGalleryProduct(null);
  setShowWorkerModal(false);
  setExcelModalOpen(false);
  setEditingProduct(null);
  setSelectedJobForWorkers(null);
}, [mainTab, recruitTab]);
```
- 관리자가 쇼핑몰 관리, 구인 관리, 위탁 판매 관리 탭 간을 이동하거나, 구인 관리 내에서 하위 탭(구인현황, 근무자/문자, 실시간 소통)을 전환할 때 열려 있던 모든 팝업 모달이 즉시 언마운트되도록 보장했습니다.

### 2.2 갤러리 모달 닫기 제어 보강
- `<div role="dialog">` 상단에 명시적인 `aria-label="갤러리 닫기"` 엑스 버튼 제공.
- 모달 하단에 `[data-testid="admin-gallery-close"]`와 `'닫기'` 텍스트 버튼 추가.
- 모달 바깥 백드롭 영역 클릭 시 자동 닫힘(`onClick={(e) => { if (e.target === e.currentTarget) setGalleryProduct(null); }}`) 구현.
- 테스트 자동화용 `window.__lrCloseAdminModals` 전역 헬퍼 제공.

## 3. 엄격한 최고관리자 인가 가드 (`ProtectedAdminView.tsx`)

- 일반 고객(`user.role !== 'admin'`) 또는 비로그인 게스트가 `SHOP_ADMIN` 뷰로 전환을 시도할 경우:
  1. 접근 차단 경고 토스트(`'최고관리자 권한이 필요한 페이지입니다.'`) 노출.
  2. 쇼핑몰 메인 화면(`SHOP_MAIN`)으로 강제 리다이렉트.
  3. 관리자 대시보드 컴포넌트 렌더링 원천 차단.
