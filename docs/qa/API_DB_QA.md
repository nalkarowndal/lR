## 2. API 및 DB 테스트 세부 내역

### 2.1 SQLite 외래 키 무결성
- `PRAGMA foreign_keys = ON;` 상시 활성화 확인.
- `PRAGMA foreign_key_check;` 실행 결과: 0건 위반.
- **결과**: **PASS**

### 2.2 추천 상품 API 20대 여성 4개 검증
- **엔드포인트**: `GET /api/v1/products/recommendations?target=20대 여성`
- **응답 코드**: `200 OK`
- **반환 건수**: 4개
  1. 생로랑 르 5 아 7 숄더백
  2. 발렌시아가 르 시티 미디엄
  3. 샤넬 캐비어 호보백
  4. 루이비통 스피디 반둘리에 25
- **결과**: **PASS (AssertionError: 3 !== 4 해결 완료)**

### 2.3 관리자 상품 등록 지속성 검증
- **흐름**: 입력 검증 -> `POST /api/v1/admin/products` -> SQLite 저장 -> 반환값 확인 후 목록 반영.
- **에러 시뮬레이션**: 잘못된 페이로드 전송 시 400 거부 및 프런트엔드 오류 팝업 출력, 폼 보존.
- **결과**: **PASS**

### 2.4 위탁 판매 사전 확인 모달 검증
- 브랜드 선택 시 즉각적인 무조건 접수 대신 사전 확인 모달 단계 확인.
- 취소 시 요청 취소, 확인 시에만 `POST /api/v1/sell-requests` 실행 및 성공 팝업 확인.
- **결과**: **PASS**
