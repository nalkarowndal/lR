# luxuryRental 사용자·관리자 계정 및 역할 설계서 (ACCOUNT_ROLE_DESIGN)

## 1. 역할 체계 (Role Architecture)

luxuryRental의 권한 체계는 두 가지 독립된 차원으로 엄격히 분리됩니다.

```text
┌────────────────────────────────────────────────────────────────┐
│ 1. 계정 권한 (UserRole) - 서버 DB 검증                            │
│    - USER : 일반 고객 (쇼핑몰, 마이페이지, 공통 설정 이용 가능)       │
│    - ADMIN: 최고관리자 (일반 고객 기능 100% 이용 + 관리자 대시보드 권한)│
└────────────────────────────────────────────────────────────────┘
                               ▲
                               │ 독립
                               ▼
┌────────────────────────────────────────────────────────────────┐
│ 2. 관리자 업무 모드 (AdminWorkspaceMode) - 대시보드 내부 UI 뷰 상태  │
│    - STORE  : 쇼핑몰 상품 등록 및 갤러리 관리 모드                  │
│    - ADMIN  : 파트너 채용 및 매장 근무자 인재풀 관리 모드              │
└────────────────────────────────────────────────────────────────┘
```

> **중요 원칙**: 프런트엔드의 상태 변경(`setRole`)은 화면 전환용일 뿐, 서버의 실제 권한을 부여하지 않습니다. 모든 보안 검증은 세션 토큰에 바인딩된 `req.user.role`에 근거합니다.

## 2. 역할별 기능 접근 권한 매트릭스 (RBAC Matrix)

| 화면 및 기능 | 비로그인 (GUEST) | 일반 고객 (USER) | 최고 관리자 (ADMIN) | 비고 |
|:---|:---:|:---:|:---:|:---|
| **메인 화면 (SHOP_MAIN)** | O | O | O | 기본 쇼핑몰 홈 |
| **카테고리 / 브랜드 (SHOP_CATEGORY)** | O | O | O | 상품 탐색 |
| **상품 검색 오버레이** | O | O | O | 검색 및 추천 키워드 |
| **내 상품 판매 접수 (SHOP_SELL)** | O | O | O | 위탁 판매 신청 |
| **관심 상품 찜하기 (FAVORITES)** | X (로그인 유도) | O | O | 개인 위시리스트 |
| **공통 설정 페이지 (SHOP_SETTINGS)** | O (기본 정보) | O (전체 설정) | O (전체 설정 + 관리자 카드) | 공통 설정 |
| **마이페이지 (SHOP_MY_PAGE)** | X (로그인 유도) | O (일반회원 뱃지) | O (관리자 뱃지 + 대시보드 링크) | 사용자 활동 |
| **프로필 정보 수정** | X | O (본인 정보만) | O (본인 정보만) | 권한상승 시도 원천 차단 |
| **비밀번호 변경** | X | O (현재 비번 검증) | O (현재 비번 검증) | 단방향 솔트 해싱 |
| **관리자 대시보드 진입 메뉴** | X (미노출) | X (미노출) | **O (노출)** | 설정 페이지 카드 |
| **관리자 대시보드 화면 (SHOP_ADMIN)** | X (차단) | X (차단) | **O (접근 허용)** | `ProtectedAdminView` |
| **관리자 REST API (`/api/v1/admin/*`)** | 403 Forbidden | 403 Forbidden | **200 OK** | `requireAdmin` 미들웨어 |

## 3. 관리자 계정의 일반 고객 기능 보장

최고관리자(`ADMIN`) 계정은 관리자 대시보드에만 갇혀 있는 것이 아니며, 일반 고객과 완전히 동일하게 쇼핑몰에서 상품을 둘러보고, 찜하고, 마이페이지를 이용할 수 있습니다.
- 관리자 계정으로 마이페이지 진입 시 상단에 "👑 관리자 계정" 뱃지가 부여됩니다.
- 마이페이지 내에 "통합 관리자 대시보드 바로가기" 버튼이 제공되어 업무와 쇼핑 경험을 유연하게 전환할 수 있습니다.
