## 2. 주요 개선 항목 분석

### 2.1 공식 소셜 로그인 버튼 및 벡터 에셋 규격화
- **기존 문제점**:
  - 네이버, 페이코 버튼이 단순 텍스트('N', 'P')로 렌더링되어 브랜드 가이드라인을 미준수함.
  - 카카오, 애플 버튼에 공식 심볼 벡터 아이콘이 부재하여 시각적 신뢰도가 부족함.
- **개선 결과**:
  - `frontend/src/components/ui/AuthSymbols.tsx`에 4대 공식 플랫폼 벡터 SVG 컴포넌트 구축.
  - **카카오**: `#FEE500` 공식 배경색 + `#000000` 공식 말풍선 심볼.
  - **Apple**: 순백색 버튼 + `#1A1A1A` 보더 + `#000000` 공식 사과 심볼.
  - **네이버**: `#03C75A` 공식 녹색 원형 버튼 + `#FFFFFF` 정밀 N 심볼.
  - **PAYCO**: `#EA3323` 공식 레드 원형 버튼 + `#FFFFFF` 정밀 P 심볼.
  - 모든 에셋은 `frontend/public/assets/auth/`에 독립 벡터 파일로도 보존됨.

### 2.2 이메일 로그인 '빠른 테스트' 및 자동 입력 영역 완전 제거
- **보안 위협 요소**:
  - 기존 운영 코드에 관리자(`admin@luxuryrental.com` / `admin1234!`) 및 일반회원 계정 비밀번호가 평문으로 노출되어 있었음.
  - 시연용 데모 버튼이 실제 사용자에게 노출될 경우 무단 계정 접근 및 데이터 변조 위험 발생.
- **조치 사항**:
  - `ShopLike.tsx`에서 `handleFillDemo` 함수 및 관련 안내 배너, 버튼 일체 삭제.
  - 프런트엔드 소스코드 내 비밀번호 하드코딩 완전 제거 (OWASP A07:2021 Identification and Authentication Failures 완화).
  - '로그인 상태 유지' 체크박스 기능 연동 (`sessionStorage` vs `localStorage` 관리).

### 2.3 회원가입 약관 및 동의 체계 법적 요건 충족
- **법적 요건**:
  - 「개인정보 보호법」 제15조 및 제22조: 필수 수집 항목과 선택 수집(마케팅) 항목의 엄격한 분리 동의 필수.
  - 「전자상거래 등에서의 소비자보호에 관한 법률」 제13조: 서비스 기본 이용약관의 전문 고지 의무.
- **개선 결과**:
  - 단일 체크박스에서 **3단계 세부 동의 + 전체 동의** 구조로 전면 개편:
    1. `[전체 동의]`: 필수 및 선택 약관 일괄 토글
    2. `[필수] 서비스 이용약관 동의` + `[내용 보기]` 모달 연동
    3. `[필수] 개인정보 수집 및 이용 동의` + `[내용 보기]` 모달 연동
    4. `[선택] 혜택·이벤트 및 신상품 알림 수신 동의` + `[내용 보기]` 모달 연동
  - `LegalTermsModal` 신설: 약관 버전(`v2.1`), 시행일자(`2026년 1월 1일`), 요약 박스, 조항별 스크롤 본문 제공.
  - 회원가입(`ShopRegister`), 공통 설정(`ShopSettings`), 메인 푸터(`ShopMain`)의 약관 시스템을 `frontend/src/data/legalTerms.ts`로 100% 일원화.

### 2.4 백엔드 데이터베이스 마이그레이션 및 감사 로그
- **신규 테이블**:
  - `legal_documents`: 공식 약관 문서 버전 관리 (타이틀, 요약, 전문 본문, 필수 여부, 시행일).
  - `user_consents`: 회원별 법적 동의 이력 감사 로그 (`user_id`, `doc_type`, `version`, `agreed`, `ip_address`, `user_agent`, `created_at`).
- **RESTful API**:
  - `GET /api/v1/legal`: 활성 약관 목록 조회.
  - `GET /api/v1/legal/:docType`: 특정 약관 전문 조회.
  - `GET /api/v1/legal/user/consents`: 로그인 회원의 동의 이력 타임라인 조회.
  - `PUT /api/v1/legal/user/consents`: 마케팅 동의 상태 실시간 변경 및 감사 행 기록.
