## 3. 세부 아키텍처 감사

### 3.1 권한 및 인가 아키텍처
- 서버 측 `requireAdmin` 미들웨어는 오직 SQLite `sessions`에 연결된 사용자의 `role === 'ADMIN'`만을 신뢰합니다.
- 클라이언트 측 `ProtectedAdminView`는 비인가 사용자 또는 일반 회원이 직접 관리자 화면에 접근할 경우 즉각 접근 거부 화면을 렌더링하고 설정 페이지로 유도합니다.

### 3.2 사용자 프로필 및 환경설정 관리
- `user_settings` 테이블 신설을 통해 서비스 알림, 마케팅 알림, 상품 알림, 애니메이션 감소(`reduce_animations`) 상태를 서버 DB에 영속화했습니다.
- `favorites` 테이블 신설을 통해 회원의 관심 상품 찜 목록을 DB 기반으로 안전하게 관리합니다.
- `PATCH /api/v1/users/me` 엔드포인트는 `role` 파라미터를 철저히 배제하여, 클라이언트가 악의적으로 관리자 권한으로 승격을 시도하더라도 100% 차단됩니다.
