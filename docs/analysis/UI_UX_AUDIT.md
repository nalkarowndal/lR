# luxuryRental UI/UX 디자인 및 인터랙션 감사 보고서 (UI_UX_AUDIT)

## 1. UI/UX 고도화 목적 및 핵심 원칙

1. **기존 브랜드 디자인 언어 보존**:
   - 중앙 집중 모바일 컨테이너 (최대 폭 430px)
   - 모노톤 & 샴페인 골드(#B49A67), 딥 그라파이트(#252525) 색상 시스템
   - 상단 헤더, 하단 플로팅 내비게이션 바, 렌트/구매/판매 액션 카드 유지
2. **미완성 인터랙션 및 죽은 버튼(Dead Click) 해결**:
   - 상품 카드 클릭 시 카테고리/상세 안내 화면으로 자연스러운 화면 전환
   - 관심 상품(하트 아이콘) 클릭 시 로그인 상태에 따라 실시간 찜 등록/해제 및 사용자 DB 동기화
   - 위탁 판매 신청 시 1클릭 즉시 접수 대신 사전 확인 모달 추가 (Section 9.5)
3. **정교한 금속 각인 엠블럼 아이콘 시스템**:
   - 설정 화면의 임시 이모지 `👑`를 정교한 샴페인 골드 각인 `LuxuryCrownIcon`으로 교체

## 2. 화면별 개선 상세

### 2.1 메인 페이지 (`ShopMain.tsx`)
- **추천 상품 탭 & 카드 클릭**:
  - '20대 여성' ~ '40대 여성' 탭 전환 시 부드러운 애니메이션 적용
  - 추천 상품 카드 클릭 시 해당 상품군으로 이동하는 인터랙션 연결
- **관심 상품(Heart) 버튼**:
  - 비로그인 상태: 로그인 유도 안내 토스트와 함께 로그인 오버레이 호출
  - 로그인 상태: 백엔드 `/api/v1/users/me/favorites/:id`와 연동하여 실시간 좋아요 토글 및 하트 채움(`fill="#EF4444"`) 반영
- **신규 입고 렌탈 상품(Rent New Arrivals)**:
  - 1:1 정사각형 고화질 스튜디오 룩북 이미지 비율 유지
  - 카드 클릭 시 카테고리 뷰로 연결

### 2.2 카테고리 페이지 (`ShopCategory.tsx`)
- **브랜드 상품 카드 인터랙션**:
  - 브랜드 칩(루이비통, 구찌, 샤넬 등) 선택 시 2열 그리드 상품 카드 정상 렌더링
  - 카드 클릭 시 상품 안내 인터랙션 및 하트 버튼 찜 동기화 연결
- **서브카테고리 탭**:
  - 서브카테고리 클릭 시 선택 상태 배지 강조 및 필터 토스트 안내

### 2.3 내 상품 판매 (`ShopSell.tsx`)
- **사전 확인 모달 단계 추가**:
  - 브랜드 선택 시 즉시 API가 호출되던 방식을 개선
  - 선택한 브랜드명, 감정팀 무료 수거, 공인 명품 감정원 정품 인증, 렌탈 정산 수익 안내를 포함한 확인 모달을 거친 후 최종 신청 접수

### 2.4 설정 페이지 (`ShopSettings.tsx`)
- **관리자 엠블럼 고도화**:
  - 프로필 요약 카드에 표시되던 기본 유니코드 이모지 `👑`를 럭셔리 각인 `LuxuryCrownIcon`으로 교체
- **설정 저장 결과 피드백**:
  - 알림 및 애니메이션 토글 변경 시 서버 API 지속성을 검증하고, 실패 시 롤백 및 에러 토스트 표시

### 2.5 관리자 센터 (`ShopAdmin.tsx`)
- **위탁 판매 신청 관리 탭 신설**:
  - `mainTab === 'SELL_REQUESTS'` 탭을 추가하여 고객이 신청한 위탁 판매 건(브랜드명, 신청자, 연락처, 접수일시)을 실시간 모니터링
  - 전문감정중, 판매승인, 반려 등 상태 변경 기능 제공
