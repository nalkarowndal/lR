# LuxuryRental Phase 3 스크린샷 재감사 및 결함 수정 보고서 (Re-Audit)

## 1. 개요 및 목적

Phase 3에서 생성된 전체 81개 스크린샷에 대한 픽셀 단위 정밀 재감사를 실시하고, 기존 자동화 스크립트의 비동기 타이밍 오차, React 상태 불일치, 잔여 오버레이 누수 등으로 인해 발생했던 5대 핵심 결함을 근본적으로 분석하고 완전히 수정하였습니다.

---

## 2. 발견된 5대 핵심 결함 및 수정 내역

### 2.1 [결함 1] 데스크톱 검색창 0px 정렬 및 스크롤 밀림 방지 (Screenshot #26)
- **원인 분석**: 1440px 데스크톱 환경에서 검색 오버레이가 슬라이드인 애니메이션(300ms) 진행 도중 입력창(`input`)에 강제 포커스를 부여하여 화면이 가로로 약 130px 밀려 좌측 영역이 잘리는 현상 발생.
- **수정 조치**: 
  - 슬라이드 애니메이션이 100% 완료된 후(`320ms`) `focus({ preventScroll: true })` 및 `window.scrollTo({ left: 0 })`를 적용하여 0px 정렬 상태를 보장.
  - W3C WAI-ARIA Modal Focus Trap을 구현하여 포커스가 대화상자 외부로 빠져나가지 않도록 완벽 제어.

### 2.2 [결함 2] 비로그인 찜 클릭 시 오버레이 누수 현상 (Screenshot #11)
- **원인 분석**: 비로그인 상태에서 하트 아이콘 클릭 시 로그인 유도 오버레이가 표시되는데, 테스트 스크립트의 닫기 버튼 선택자(`button[aria-label="닫기"]`)가 `ShopLike.tsx`의 `aria-label="로그인 창 닫기"`와 불일치하여 오버레이가 닫히지 않고 다음 캡처 프레임으로 누수되는 문제.
- **수정 조치**: 
  - `AppContext`에 `window.__lrSetOverlay(null)` 및 `window.__lrNavigate(view)` 전역 헬퍼를 노출하여 각 테스트 케이스 전환 시 잔여 오버레이를 100% 격리 및 강제 해제.

### 2.3 [결함 3] 검색어 칩 클릭 시 이전 검색 결과 잔존 현상 (Screenshot #30)
- **원인 분석**: 입력창의 값을 DOM API(`el.value = ''`)로 직접 비웠을 때 React의 Synthetic Event `onChange`가 트리거되지 않아 내부 state(`searchQuery`)가 `"스톤 아일랜드"`로 유지되어, 추천 태그 `"까르띠에"`를 클릭했음에도 스톤 아일랜드 결과가 잔존 노출됨.
- **수정 조치**:
  - `button[aria-label="검색어 지우기"]`를 클릭하거나 state를 직접 갱신하도록 수정.
  - 검색어가 변경되는 즉시 `searchResults`를 빈 배열(`[]`)로 리셋하고 스켈레톤 로더(Skeleton Cards)를 노출하여 이전 쿼리 잔상이 전혀 노출되지 않도록 동기화.

### 2.4 [결함 4] 비밀번호 재설정 모달 선택자 불일치 (Screenshot #36, #37)
- **원인 분석**: `ShopPasswordReset.tsx` 컴포넌트의 실제 placeholder `"가입된 이메일 입력"` 및 버튼 텍스트 `"재설정 안내 받기"`와 자동화 스크립트의 문자열이 어긋나 Step 2로 정상 진입하지 못했던 문제.
- **수정 조치**: 정확한 placeholder 및 버튼 텍스트를 매칭하고, 이메일 요청 시 모의 토큰 발송 및 Step 2 비밀번호 변경 폼이 정상 렌더링되도록 동기화 완료.

### 2.5 [결함 5] 카테고리 화면 내비게이션 바 부재로 인한 이동 실패 (Screenshot #38~#50)
- **원인 분석**: `ShopCategory.tsx`는 전체 화면 카테고리 뷰로 하단 내비게이션 바가 숨겨지는 구조인데, `clickByText('span', '판매')`를 시도하여 내비게이션 실패가 발생.
- **수정 조치**: 카테고리 화면 이동 시 `window.__lrNavigate('SHOP_SELL')`를 안전하게 호출하거나 뒤로가기 처리를 거치도록 테스트 러너 로직을 방어적으로 개선.

## 3. 결론

5대 결함에 대한 근본적인 수정과 상태 격리를 통해 81개 스크린샷 전부에 대해 가짜 성공(False Positive)이나 중복 프레임 없는 진정한 100% 자동화 시각 회귀 테스트 환경을 달성하였습니다.
