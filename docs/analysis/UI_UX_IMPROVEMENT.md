# luxuryRental UI/UX 전면 품질 고도화 계획서 (UI_UX_IMPROVEMENT)

## 1. 디자인 보존 및 고도화 기본 원칙

1. **디자인 보존 원칙**:
   - 모바일 컨테이너(`max-w-md`)와 데스크톱 고정 QR 다운로드 배너의 레이아웃을 100% 보존합니다.
   - 기존의 모든 브랜드명, 상품명, 가격, 할인율, 렌트/구매/판매 탭, 관리자 글래스모피즘 다크테마를 원형 그대로 유지합니다.
   - 46개 기준 스크린샷의 모든 시각적 요소와 셀렉터를 유지합니다.
2. **품질 고도화 원칙**:
   - 저품질 이모지 및 SVG 아이콘만 표시되던 상품 영역에 실제 고품질 스튜디오 패션 사진을 적용합니다.
   - 로그인 화면에 이메일/비밀번호 입력 폼을 자연스럽게 탭 또는 확장 영역으로 결합하고, 전용 회원가입 페이지와 계정 찾기 화면을 구축합니다.
   - 파편화된 브라우저 `alert()`와 제각각인 모달을 공통 모달/토스트 시스템으로 통합합니다.
   - 절제된 럭셔리 모션 시스템(Fade, Subtle Scale, Slide-in)을 적용하여 부드러운 반응을 구현합니다.

## 2. 화면별 UI/UX 고도화 세부 계획

### 2.1 메인 홈 (`ShopMain.tsx`)
- **헤더 영역**:
  - 미로그인 시 기존과 같이 '간편 로그인' 유도, 로그인 완료 시 '사용자명' 뱃지 및 프로필/로그아웃 팝오버 제공.
- **회원가입 이벤트 배너**:
  - '지금 가입하면 첫 렌트 70% 할인' 배너 클릭 시 신규 회원가입 페이지로 즉시 이동.
- **상품 카드 렌더링**:
  - `ProductImage` 컴포넌트를 통해 고해상도 스튜디오 룩북 이미지 렌더링.
  - 로딩 중에는 부드러운 스켈레톤 펄스 효과, 이미지 로드 실패 시 기존의 세련된 `ProductVisualBadge` SVG로 안전한 Fallback.

### 2.2 카테고리 및 브랜드 (`ShopCategory.tsx`)
- **카테고리 뷰**:
  - 8대 대분류 및 서브카테고리 선택 시 실제 상품 사진과 매핑된 상품 리스트 노출.
- **브랜드 뷰**:
  - 브랜드 칩 선택 시 해당 브랜드의 실제 상품 사진과 메타데이터 필터링.

### 2.3 통합 검색 (`ShopSearch.tsx`)
- **검색 UI**:
  - 실시간 입력 디바운스 및 검색 결과 카드에 실물 상품 이미지 표시.
  - 검색어 지우기(X) 버튼, 추천 검색어 클릭 시 즉시 쿼리 반영, ESC 단축키 지원.

### 2.4 내 상품 판매 (`ShopSell.tsx`)
- **비동기 UX 개선**:
  - 브랜드 선택 및 직접 등록 신청 시 "신청 접수 중..." 로딩 스피너 표시.
  - 백엔드 DB 저장 완료 시 성공 모달 표출, 에러 발생 시 안내 모달 표출.

### 2.5 로그인 및 회원가입 (`ShopLike.tsx`, `ShopRegister.tsx`, `ShopPasswordReset.tsx`)
- **로그인 오버레이/페이지**:
  - 기존의 상단 LUXURYRENTAL 로고, 카카오/Apple/네이버/페이코 소셜 버튼 레이아웃을 완벽히 유지.
  - 상단 또는 하단에 "이메일 로그인" 폼(이메일, 비밀번호, 비밀번호 보기/숨기기 토글, 로그인 버튼, 자동로그인 체크)을 매끄럽게 배치.
  - "회원가입", "계정 찾기" 링크를 통해 신규 회원가입 및 비밀번호 재설정 모달로 자연스럽게 전환.
- **회원가입 전용 화면 (`ShopRegister.tsx`)**:
  - 브랜드 스타일에 맞춘 프리미엄 폼: 이메일(중복확인 실시간 검증), 비밀번호(영문+숫자+특수문자 강도 인디케이터), 비밀번호 확인, 이름, 휴대폰 번호.
  - 약관 동의 체크박스(이용약관 필수, 개인정보 수집 필수, 마케팅 수신 선택).
  - 가입 완료 시 감각적인 체크 애니메이션 및 환영 토스트.

### 2.6 관리자 대시보드 (`ShopAdmin.tsx`)
- **상품 갤러리 관리**:
  - 딥 다크 테마 글래스모피즘 보존.
  - 신규 상품 등록 시 이미지 파일 업로드 / 미리보기 / 대표 이미지 지정 기능 탑재.
  - 등록된 상품의 이미지 갤러리 썸네일 그리드 제공.

## 3. 디자인 시스템 토큰 규격

- **Primary Colors**: Black `#0a0a0a`, Charcoal `#171717`, Pure White `#ffffff`
- **Secondary Colors**: Gray-50 `#f9fafb`, Gray-100 `#f3f4f6`, Gray-200 `#e5e7eb`
- **Accent Colors**: Luxury Indigo `#4C51F7`, Emerald Success `#10b981`, Rose Error `#f43f5e`
- **Typography**: Pretendard / System Font, 고대비 및 가독성 준수
- **Border Radius**: 12px (`rounded-xl`), 16px (`rounded-2xl`)
- **Shadows**: Soft Ambient `shadow-[0_2px_8px_rgba(0,0,0,0.04)]`, Elevated `shadow-xl`
