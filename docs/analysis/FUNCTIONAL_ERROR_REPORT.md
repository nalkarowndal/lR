# LuxuryRental 시스템 기능 오류 종합 감사 및 수정 완료 보고서

## 1. 개요

본 문서는 `luxuryRental` 시스템의 전 영역(프론트엔드 React 19, 백엔드 Express/TypeScript, SQLite DB, 보안 미들웨어, 비즈니스 계산 로직)에서 식별된 기능적 오류 및 사용성 결함의 원인과 해결 방안을 체계적으로 정리한 종합 보고서입니다.

---

## 2. 주요 기능 오류 및 해결 내역

### 2.1 [P0] 렌탈 기간별 가격 계산 모순 및 정가 역전 오류
- **문제점**: 30일 대여료(805,000원)가 취소선으로 표시되는 정가(350,000원)를 초과하여, 할인 서비스임에도 정가보다 비싼 것으로 오인되는 현상.
- **해결 방안**: 
  - `frontend/src/utils/pricing.ts` 모듈 신규 구현.
  - 선택 기간에 맞춰 기준 정가를 동적 스케일링($\text{Base Price} = \max(\frac{\text{Original}}{3} \times \text{days}, \text{Price} \times 1.45)$).
  - 3일(67%), 7일(70%), 15일(74%), 30일(77%)로 일관된 할인율 및 1일 환산 요율 단조 감소 보장.

### 2.2 [P0] 장바구니 결제 및 주문 내역 연동 부재
- **문제점**: 기존 장바구니에서 '렌탈 주문 신청하기'를 클릭하면 배송지 정보 입력이나 주문 번호 생성 없이 단순 알림 후 장바구니만 비워지고 마이페이지에 주문이 기록되지 않음.
- **해결 방안**:
  - 장바구니를 3단계(`CART` -> `SHIPPING` -> `ORDER_COMPLETE`) 모의 주문 플로우로 전면 개편.
  - 수령인 성명, 연락처, 배송지 주소, 배송 메모 입력 및 유효성 검증.
  - 고유 주문번호(`LR-YYYYMMDD-XXXX`) 생성 및 `localStorage('luxury_orders')` 영구 보관.
  - 마이페이지 `이용 중인 렌탈` 탭에서 실시간 주문 카드 및 배송 준비 상태 연동 노출.

### 2.3 [P1] 검색 쿼리 변경 시 이전 검색 결과 잔존 및 로딩 지연
- **문제점**: 검색어 변경 시 이전 결과가 그대로 남아있다가 디바운스 완료 후 튀는 현상 발생, 카테고리별 필터링 기능 부재.
- **해결 방안**:
  - `searchQuery` 변경 즉시 `searchResults`를 빈 배열로 초기화하고 4개 스켈레톤 로더(Skeleton Cards)를 즉시 노출.
  - 비동기 경쟁 상태(Race Condition) 방지를 위한 `isCurrent` 플래그 및 타이머 취소 로직 적용.
  - 카테고리 필터 칩(전체, 가방, 의류, 슈즈, 시계/주얼리) 추가.

### 2.4 [P1] 회원가입 약관 전체 동의 체크박스 접근성 및 만 14세 이상 확인 누락
- **문제점**: '모든 약관에 전체 동의합니다'가 `<input type="checkbox">`가 아닌 `div`로 구현되어 키보드 접근성(Space/Enter) 및 스크린 리더에서 체크박스로 인식되지 않음. 만 14세 이상 법적 확인 항목 누락.
- **해결 방안**:
  - 시맨틱 `<label>` 및 접근성 `<input type="checkbox" aria-label="모든 약관에 전체 동의합니다">` 적용.
  - `[필수] 만 14세 이상입니다 (본인 확인)` 체크박스 추가 및 전체 동의 양방향 동기화.

### 2.5 [P1] 명품 판매/위탁 신청 3단계 모달 분리
- **문제점**: 기존 위탁 신청이 단일 안내창으로 처리되어 브랜드 직접 등록, 신청서 작성, 접수증 확인 구분이 모호함.
- **해결 방안**:
  - 1단계: **신규 브랜드 직접 등록 모달** (브랜드명 및 카테고리 수기 등록).
  - 2단계: **명품 위탁·판매 신청서 모달** (카테고리, S/A/B급 외관 상태, 부속품 체크리스트, 위탁/즉시매입 방식 선택, 신청자 연락처).
  - 3단계: **위탁 판매 접수 완료 모달** (접수번호 `SELL-YYYYMMDD-XXXX`, 안심 수거 키트 발송 안내).

### 2.6 [P1] 관리자 대시보드 STORE/ADMIN 모드 및 엑셀 일괄 업로드 도구
- **문제점**: 본사 ADMIN 전용 엑셀 업로드가 단순 `showAlert`로 목업되어 있었고, 매장 목록 검색/필터 기능 부재.
- **해결 방안**:
  - 상단에 **STORE MODE**와 **HQ ADMIN MODE**를 명확히 구분하는 비주얼 배지 및 전환 헤더 구현.
  - 엑셀 일괄 업로드 모달 구현: 파일 드래그앤드롭 영역, `.xlsx/.xls/.csv` 확장자 및 5MB 용량 검증, 35개 매장 TO 데이터 미리보기 테이블, 데이터베이스 일괄 반영 액션.
  - 쇼핑몰 관리 테이블에 상품명/브랜드 실시간 검색 및 렌탈/구매 필터 추가.
